# Ontiqo Homebrew tap

Mac apps from [Ontiqo](https://ontiqo.com), for [Homebrew](https://brew.sh).

```sh
brew install --cask ontiqo/tap/omninput
brew install --cask ontiqo/tap/echofiles
```

| Cask | App |
|---|---|
| `echofiles` | [Echofiles](https://echofiles.app): keeps folders in sync between your own computers, peer to peer |
| `omninput` | [Omninput](https://omninput.app): one keyboard, mouse and monitor across Windows, macOS and Linux |

Casks here are kept up to date by Ontiqo, with the help of an AI coding assistant (Claude).
